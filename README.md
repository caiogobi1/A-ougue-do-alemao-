# Açougue do Alemão 🥩

Aplicativo do **Açougue do Alemão**, em Jundiaí/SP.

## Objetivo
Criar um aplicativo para Android e iPhone para facilitar os pedidos dos clientes, com opções de delivery e retirada no açougue.

## Primeira versão
- 🥩 Catálogo de carnes e produtos
- 🛒 Carrinho de compras
- 🛵 Delivery
- 🏪 Retirada no açougue
- 💳 Pagamento por Pix, cartão de débito e cartão de crédito
- 📲 Finalização e contato pelo WhatsApp
- 🔥 Área de ofertas
